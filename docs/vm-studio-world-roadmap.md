# VM Studio — VM Belfort World

Private development roadmap, 2026-11-25. No production deployment.

## Shared world
One streamed 3D city, shared asset registry, LOD, lighting, weather, input and performance telemetry. Separate game rules and physics adapters. Start with a small high-quality neighborhood; expand to Belfort using licensed geographic data. Military combat uses fictional arenas, not real attack scenarios. Fictional teams and districts for territory competition.

## Modes
- Sous le Lion: fictional military FPS.
- Open World: exploration, jobs, vehicles, fictional territory challenges.
- Auto, Moto, Rally: closed-course racing, shared vehicle assets.
- Simulation: civilian driving and activities.
- Football des Clubs: independent game sharing studio tooling, not the city runtime.
